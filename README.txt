BEA TADEO NAVATA PORTFOLIO — VS CODE (NO NODE.JS REQUIRED)

1. Extract the ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder, and select the Bea_Portfolio folder.
4. Add your pictures into the indicated folders, using the exact filenames below.
5. Open index.html in a browser (right-click the file in VS Code and choose "Reveal in File Explorer", then double-click it).
   Optional: install the Live Server extension in VS Code, then right-click index.html > Open with Live Server.
